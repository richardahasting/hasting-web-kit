hasting-feedback harness

Checklist:

  1. Page loads with no visible modal — button only.
  2. Button opens the modal; ESC, ✕, Cancel, and overlay click close it.
  3. Short text (<10 chars) shows an inline error.
  4. Attach / paste (Ctrl+V) / drag-drop an image → preview appears; Remove works.
  5. A non-image or >5 MB file shows an error, not a crash.
  6. Send with the service down → "Could not reach the server."
  7. Send with the local service up → success panel, auto-close in 6 s.
